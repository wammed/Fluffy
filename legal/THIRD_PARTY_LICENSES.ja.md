## 1. 目的

本書は、Fluffy プロジェクトに関連するライセンスおよびプロヴェナンス（由来）情報を記録するものです。

Fluffy はソースコードとして配布されます。後述する外部マルチメディアランタイムを同梱または再配布することはありません。ユーザーおよびディストリビューションが各自のランタイムパッケージを提供します。

本書では以下の要素を明確に分離して扱います：

1. Fluffy 本体
2. Rust / Cargo 依存クレート
3. 外部 GStreamer ランタイムコンポーネント
4. 外部 FFmpeg ランタイムコンポーネント
5. AI 生成アートワーク / アセット
6. ダウンストリーム（下流）パッケージング

本書はプロジェクトの監査記録であり、法的助言を提供するものではありません。

---

## 2. Fluffy 本体

### ライセンス

**MIT License**

プロジェクトは以下を宣言しています：

```toml
license = "MIT"
```

リポジトリには MIT License の全文を収めた `LICENSE` ファイルが含まれています。

Fluffy が利用する外部の FFmpeg インストール環境に GPL ライセンスのコンポーネントが含まれていたとしても、それ単体によって Fluffy 本体のソースコードが GPL のもとにライセンスされることはありません。

### 配布モデル

公式プロジェクトの配布方針はソースコード配布のみです：

- 公式バイナリリリースの非提供
- AppImage の非同梱
- FFmpeg の非同梱
- GStreamer ランタイムの非同梱
- ユーザーまたはディストリビューションが対象環境向けに Fluffy をビルドおよびパッケージング

## 3. Rust / Cargo 依存関係

Fluffy は Rust の依存関係管理に Cargo を使用しています。

依存関係のライセンス監査は `cargo-deny` を用いて実施されました。

### cargo-deny 監査結果

現在の監査結果は以下の通りです：

- 勧告 (Advisories): **OK**
- 禁止クレート (Bans): **OK**
- ライセンス (Licenses): **OK**
- ソースリポジトリ (Sources): **OK**

設定されている許可ライセンス一覧：

- MIT
- Apache-2.0
- Apache-2.0 WITH LLVM-exception
- ISC
- Unicode-3.0
- Zlib

未知のレジストリおよび未知の Git ソースは、現在の `deny.toml` 設定により拒否されます（COSMIC デスクトップ公式の `cosmic-protocols` Git ソースのみ `allow-git` にて明示的に許可）。

### 重複クレートバージョン

`cargo-deny` は `syn` の複数バージョンに対して警告を報告しています：

- `syn 2.0.119`
- `syn 3.0.6`

これは間接的（推移的）な依存関係によるものであり、Fluffy の直接の依存関係ではありません。

現在の設定では複数バージョンの存在は `deny` ではなく `warn` に設定されています。ライセンス上の違反は報告されていません。

## 4. GStreamer

GStreamer は動画再生のために Fluffy が利用する外部ランタイム依存関係です。

Fluffy は GStreamer を同梱しません。

### 4.1 監査対象 CachyOS パッケージ

開発・テスト環境は `cachyos-extra-v3` のパッケージを使用する CachyOS です。

以下のパッケージを `pacman -Qi` で検査しました：

| パッケージ | バージョン | 報告されたライセンス |
|---|---:|---|
| `gstreamer` | 1.28.7-2.1 | LGPL-2.1-or-later |
| `gst-plugins-base` | 1.28.7-2.1 | LGPL-2.1-or-later |
| `gst-plugins-good` | 1.28.7-2.1 | LGPL-2.1-or-later |
| `gst-plugins-bad` | 1.28.7-2.1 | LGPL-2.1-or-later |
| `gst-libav` | 1.28.7-2.1 | LGPL-2.1-or-later |

インストールされている実行ファイル `gst-launch-1.0` および `gst-inspect-1.0` は `gstreamer` パッケージによって提供されます。

`gst-libav` は外部にインストールされた `ffmpeg` パッケージに依存します。

### 4.2 監査対象 GStreamer プラグイン

同一テスト環境下で `gst-inspect-1.0` を用いて以下のランタイムコンポーネントを検査しました：

| コンポーネント | バージョン | 報告されたライセンス |
|---|---:|---|
| `waylandsink` | 1.28.7 | LGPL |
| `h264parse` | 1.28.7 | LGPL |
| `qtdemux` | 1.28.7 | LGPL |
| `decodebin` | 1.28.7 | LGPL |
| `nvh264dec` | 1.28.7 | LGPL |
| `avdec_h264` | 1.28.7 | LGPL |

これらの検査は、監査環境において確認されたランタイムコンポーネントを記録するものです。すべての GStreamer プラグイン導入環境において同一のライセンス体系となることを保証するものではありません。

### 4.3 ランタイムの配布

ユーザーおよびディストリビューションは、オペレーティングシステムまたはパッケージリポジトリから GStreamer を取得します。Fluffy は検査対象となった GStreamer バイナリやプラグインを再配布しません。

上記のパッケージレベルおよびプラグインレベルの結果は、プロジェクト監査に使用された特定の CachyOS 環境を記述したものです。

## 5. FFmpeg

FFmpeg はメディア検証およびフォーマット変換のための外部プロセスとして使用されます。

関連する外部コマンド：

- `ffprobe`
- `ffmpeg`

変換パイプラインでは以下を使用します：

```text
-c:v libx264
```

したがって、導入されている FFmpeg ランタイムはこの変換パスのために `libx264` サポートを提供している必要があります。

### 5.1 監査対象 CachyOS パッケージ

監査環境：

- OS: CachyOS
- パッケージソース: `cachyos-extra-v3`
- パッケージ: `ffmpeg`
- パッケージバージョン: `2:9.0.2-1.1`
- FFmpeg バージョン: `n9.0.2`
- アーキテクチャ: `x86_64_v3`

インストールされたパッケージの報告：

```text
Licenses : GPL-3.0-only
```

FFmpeg のビルド構成には以下が含まれています：

```text
--enable-gpl
--enable-libx264
```

また、インストールされたパッケージは `x264` パッケージに依存しています。

`ffmpeg -L` は、この FFmpeg ビルドが GNU General Public License のもとで配布されていることを報告しています。

### 5.2 ライセンス上の重要な区別

インストールされた FFmpeg ランタイムの GPL ライセンスは、Fluffy 本体のライセンスを**変更するものではありません**。

関係性は以下の通りです：

```text
Fluffy (MIT)
    |
    +-- 外部プロセス呼び出し --> ffprobe / ffmpeg
                                   |
                                   +-- 監査環境: GPL-3.0-only FFmpeg
                                   +-- libx264
```

Fluffy のソース配布にはこの FFmpeg バイナリは含まれません。

したがって、インストールされる FFmpeg ビルドのライセンスは、ユーザーまたはディストリビューターの環境における外部ランタイムの検討事項となります。

ディストリビューションによって、異なる構成オプションやパッケージメタデータを持つ FFmpeg ビルドが提供される場合があります。上記の GPL-3.0-only の結果は、本プロジェクトのために監査された特定の CachyOS 環境におけるものです。

### 5.3 GStreamer との関係

監査された `gst-libav` パッケージの報告：

```text
Licenses : LGPL-2.1-or-later
```

また、外部の `ffmpeg` パッケージを依存関係として宣言しています。

これらは別個のパッケージレベルのライセンス記録です：

- `gst-libav`: LGPL-2.1-or-later
- 監査対象 CachyOS 環境における `ffmpeg`: GPL-3.0-only

`gst-libav` が報告する LGPL ライセンスは、別パッケージとして提供される FFmpeg ランタイムのライセンスを変更するものと解釈すべきではありません。

### 5.4 別途考慮事項: コーデックおよび特許問題

ソフトウェアライセンスとコーデック・特許に関する考慮事項は別個の問題です。

本書はテスト対象となった FFmpeg パッケージにおいて確認されたソフトウェアライセンス情報を記録するものです。特許やコーデックに関する法的評価を提供するものではありません。

## 6. AI 生成アートワーク / アイコン

Fluffy には AI 画像生成ワークフローを使用して作成されたアートワークが含まれています。

現在のプロジェクト記録：

- Google Gemini アプリを用いてベースアートワークを生成
- プロジェクト記録モデル名: **Nano Banana**
- プロジェクト記録生成日: **2026-09-26**
- 生成されたベースアートワークは、その後に人間によって修正・加工
- 第三者意匠との類似性検査は未実施

関連するプロジェクト記録：

- [`IP_COMPLIANCE.ja.md`](IP_COMPLIANCE.ja.md)
- [`ICON_DESIGN_HISTORY.ja.md`](ICON_DESIGN_HISTORY.ja.md)

プロジェクト監査において個別の `ASSET_PROVENANCE.md` ファイルは確認されませんでした。

### 取り扱い方針

AI 生成アートワークは、ソフトウェアの依存関係とは明確に区別して管理されます。

Fluffy 本体が MIT ライセンスであることのみを理由として、AI 生成アートワークを通常のサードパーティ製ソフトウェア依存関係として記述したり、ソフトウェアライセンスを一律に適用したりするべきではありません。

由来（プロヴェナンス）および適用される権利・利用規約は、プロジェクトのアセット・プロヴェナンス記録において文書化され続ける必要があります。

## 7. サードパーティ製ソースコード / ベンダーコード

プロジェクト監査では以下の専用ディレクトリは確認されませんでした：

- `vendor/`
- `third_party/`
- `licenses/`
- `LicenseS/`

コピーされたサードパーティ製ソースコードを含むディレクトリは存在しません。

したがって、プロジェクトは現在、外部の GStreamer または FFmpeg ランタイムのベンダー（同梱）コピーを再配布していないと判断されます。

Cargo 依存関係はそれぞれのパッケージライセンスに従い、Cargo 依存関係監査を通じて追跡されます。

## 8. ダウンストリーム（下流）パッケージング

Fluffy は、公式の同梱マルチメディアランタイムと共に出荷されるのではなく、ディストリビューションやユーザーによってパッケージングされることを想定しています。

下流のパッケージャーは各自で以下を独立して検証する必要があります：

- パッケージに含まれる、またはパッケージが要求する正確な GStreamer プラグイン
- パッケージが使用する正確な FFmpeg パッケージ／ビルド
- 再配布する追加ランタイムコンポーネントのライセンス
- ディストリビューション固有のパッケージング義務

下流パッケージャーは、開発環境で確認された FFmpeg や GStreamer のライセンスが、あらゆるディストリビューションに一律に適用されるとみなすべきではありません。

## 9. 監査ステータス

| 領域 | ステータス | 備考 |
|---|---|---|
| Fluffy 本体ライセンス | 合格 (PASS) | MIT |
| Cargo 依存クレートライセンス | 合格 (PASS) | `cargo-deny`: licenses OK |
| Cargo 依存ソース | 合格 (PASS) | `cargo-deny`: sources OK |
| Cargo 脆弱性勧告 | 合格 (PASS) | `cargo-deny`: advisories OK |
| Cargo 重複バージョン | 警告 (WARN) | `syn` に複数の推移的バージョンあり |
| GStreamer パッケージライセンス | 合格 (PASS)* | 監査対象パッケージは LGPL-2.1-or-later を報告 |
| GStreamer プラグインライセンス | 合格 (PASS)* | 検査対象プラグインは LGPL を報告 |
| FFmpeg ランタイム | 文書化済み (DOCUMENTED)* | テスト対象 CachyOS パッケージは GPL-3.0-only |
| AI アートワークの由来 | 文書化済み (DOCUMENTED)* | 既存プロジェクト記録あり。類似性検査は未実施 |
| ベンダー同梱サードパーティソース | なし (NONE FOUND) | 専用の vendor/third-party ディレクトリは存在せず |

`*` これらの項目は監査・テストを実施した環境およびプロジェクト記録を記述したものであり、すべてのユーザー環境やアセットに対する普遍的な声明ではありません。

## 10. 監査エビデンス

外部ランタイムの監査は、以下のコマンドを用いて CachyOS 開発・テスト環境上で実施されました：

```text
gst-launch-1.0 --version
gst-inspect-1.0 <plugin>
pacman -Qo "$(command -v gst-launch-1.0)"
pacman -Qo "$(command -v gst-inspect-1.0)"
pacman -Qi gstreamer
pacman -Qi gst-plugins-base
pacman -Qi gst-plugins-good
pacman -Qi gst-plugins-bad
pacman -Qi gst-libav

ffmpeg -L
ffmpeg -version
ffmpeg -buildconf
ffmpeg -encoders
pacman -Qo "$(command -v ffmpeg)"
pacman -Qi ffmpeg
```

本監査は、プロジェクトレビュー時点において確認されたパッケージおよびランタイムの状態を記録するものです。

## 11. 推奨メンテナンスタスク

依存関係またはランタイムの要件が変更された場合、その変更がライセンスまたは配布に影響を与えるときは本書を更新してください。

特に以下の点について再確認を実施してください：

1. 依存関係変更後の `cargo deny check` の実行
2. 必要なコンポーネントが変更された際の GStreamer パッケージ／プラグインのライセンス確認
3. 変換パイプラインが変更された際の FFmpeg 構成の確認
4. 新しいアートワークが追加された際の AI アセットのプロヴェナンス確認
5. 公式パッケージング対象が導入された際の下流パッケージング要件の確認

ライセンス監査は、機能互換性テストとは明確に分離して維持される必要があります。
