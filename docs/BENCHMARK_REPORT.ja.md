## 実機観察とアーキテクチャ検証結果

1. **CPU オーバーヘッド**:
   - 常駐デーモンは極めて軽量に維持されています。ハードウェアデコード機能により、デコード処理が専用の NVIDIA NVDEC ASIC へオフロードされ、CPU 負荷が最小限に抑えられています。
2. **メモリフットプリント (RSS)**:
   - メモリ消費量は予測可能な境界内に安定して収まっています。4K 解像度のデュアル同時再生時であっても RSS はコンパクトに維持され、長時間のループ再生サイクルにおいてもメモリリークはゼロであることが確認されました。
3. **GPU デコーダーオフロード**:
   - `nvh264dec` によるアクティブなハードウェアデコードの動作を実証。専用ビデオデコーダーエンジンの利用率は、パイプライン数および解像度に比例してクリーンにスケールしています。
4. **バイナリサイズ**:
   - 常駐デーモンのバイナリサイズはわずか **3.2 MB** であり、`libcosmic` GUI 依存を分離して軽量なバックグラウンドフットプリントを維持するという基本設計方針を完璧に達成しています。
