# Documentation Bilingual Rule (Bilingual Maintenance)

## Rule Summary
Whenever creating or updating documentation (`README.md`, docs in `docs/`, reports, design documents, etc.) in this repository:
1. **Always maintain paired English and Japanese documents**:
   - English: `<DOC_NAME>.md` (e.g. `README.md`, `docs/TECHNICAL_DESIGN.md`)
   - Japanese: `<DOC_NAME>.ja.md` (e.g. `README.ja.md`, `docs/TECHNICAL_DESIGN.ja.md`)
2. **Synchronous Updates**:
   - Any modification or addition to an English document MUST immediately be reflected in its Japanese counterpart with equivalent semantic accuracy, and vice versa.
3. **Cross-Language Navigation**:
   - Documents should provide clear navigation links at the top connecting both language versions (e.g., `[English](...) | [日本語](...)`).
